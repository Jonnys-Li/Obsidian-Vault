# Day 32-33：数据库基础

## 概述

本单元学习在 iOS 中使用 **SQLite** 及封装库 **FMDB**，掌握建表、增删改查、**事务**与**线程安全**（FMDatabaseQueue），为后续数据库设计与优化打基础。

## 知识点

### 1. SQLite 简介

- 轻量级、无服务器、文件型数据库，内置于 iOS 系统。
- 数据库文件一般放在 Documents 或 Caches 目录，通过路径打开。
- SQL 标准语法：建表、INSERT/UPDATE/DELETE/SELECT，WHERE、ORDER BY、LIMIT 等。

### 2. SQL 基础

- **建表**：`CREATE TABLE IF NOT EXISTS 表名 (列名 类型, ...);`，常用类型 INTEGER、TEXT、REAL、BLOB。
- **插入**：`INSERT INTO 表名 (列1, 列2) VALUES (?, ?);`
- **查询**：`SELECT 列 FROM 表名 WHERE 条件 ORDER BY 列 LIMIT n;`
- **更新/删除**：`UPDATE 表名 SET 列=值 WHERE 条件;`，`DELETE FROM 表名 WHERE 条件;`

参数化使用 `?` 占位符，避免 SQL 注入。

### 3. FMDB 核心类

- **FMDatabase**：对应一个 SQLite 数据库文件，用于执行 SQL。同一 FMDatabase 不宜在多线程间共享，应在单线程使用或配合 FMDatabaseQueue。
- **FMResultSet**：查询结果集，逐行遍历，取列值如 `stringForColumn:`、`intForColumn:`。
- **FMDatabaseQueue**：串行队列包装数据库操作，多线程安全。`[queue inDatabase:^(FMDatabase *db) { ... }];` 内执行所有 db 操作。

### 4. 事务（Transaction）

- **作用**：把多条 SQL 当作一个原子操作，要么全部成功，要么全部回滚。
- **用法**：`[db beginTransaction];` 执行多条语句后 `[db commit];` 或失败时 `[db rollback];`。FMDB 也支持 `inTransaction:` 的 block 形式，自动 commit/rollback。

### 5. 线程安全

- 不要在多线程中同时使用同一个 `FMDatabase` 实例。
- 使用 **FMDatabaseQueue**：所有数据库访问都通过 `inDatabase:` 或 `inTransaction:` 放入队列，由 FMDB 串行执行。

## 注意事项 / 常见坑

- 打开数据库后使用完毕可保持打开，或在不需要时 close；Queue 会管理 db 生命周期。
- 写操作（INSERT/UPDATE/DELETE）用 `executeUpdate:`，查询用 `executeQuery:`，注意区分返回值（BOOL vs FMResultSet）。
- 事务中若有异常，务必 rollback，否则可能锁库或数据不一致。

## 小结

- SQLite 是文件型数据库；FMDB 是 ObjC 封装，FMDatabase 单线程，FMDatabaseQueue 多线程安全。
- 增删改查用参数化 SQL；大批量写用事务提升性能。
- 多线程环境统一用 FMDatabaseQueue。
