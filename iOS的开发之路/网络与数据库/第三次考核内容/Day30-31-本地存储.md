# Day 30-31：本地存储

## 概述

iOS 应用的数据持久化有多种方式，本单元涵盖：**沙盒与文件系统**、**NSUserDefaults**、**Keychain**。掌握各自的适用场景与 API，能在实际开发中正确选型。

## 知识点

### 1. 沙盒结构

iOS 应用运行在沙盒中，只能访问自己目录下的文件：

| 目录 | 路径获取 | 用途 | 是否备份 |
|------|----------|------|----------|
| **Documents** | `NSDocumentDirectory` | 用户生成、需持久化的内容 | 是 |
| **Library/Caches** | `NSCachesDirectory` | 缓存，可重新下载的数据 | 否 |
| **Library/Preferences** | 通常通过 NSUserDefaults 间接使用 | 偏好设置 | 是 |
| **tmp** | `NSTemporaryDirectory()` | 临时文件，系统可能随时清理 | 否 |

获取路径示例（见配套示例 `SandboxHelper`）：

```objc
// Documents
NSString *docPath = [NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES) firstObject];
// Caches
NSString *cachesPath = [NSSearchPathForDirectoriesInDomains(NSCachesDirectory, NSUserDomainMask, YES) firstObject];
// tmp
NSString *tmpPath = NSTemporaryDirectory();
```

### 2. 文件系统（NSFileManager）

- **创建目录**：`createDirectoryAtPath:withIntermediateDirectories:attributes:error:`
- **写文件**：`NSData` 的 `writeToFile:atomically:` 或 `NSFileHandle`
- **读文件**：`[NSData dataWithContentsOfFile:]` 或 `NSFileManager` 的 `contentsAtPath:`
- **判断存在/删除**：`fileExistsAtPath:`、`removeItemAtPath:error:`

注意：写用户数据用 Documents，缓存用 Caches，临时用 tmp。

### 3. NSUserDefaults

- **特点**：键值对、plist 存储，适合简单配置（主题、开关、上次选项等）。
- **限制**：键值对体积不宜大；主线程同步读写；同一 App Group 内可共享。
- **API**：`standardUserDefaults`，`setObject:forKey:` / `objectForKey:`，`synchronize`（现代系统一般可省略，系统会适时写入）。

```objc
[[NSUserDefaults standardUserDefaults] setObject:@"value" forKey:@"key"];
NSString *value = [[NSUserDefaults standardUserDefaults] stringForKey:@"key"];
```

### 4. Keychain（钥匙串）

- **用途**：存储密码、token、证书等敏感信息，系统级加密，卸载应用后仍可保留（可选）。
- **API**：使用 Security.framework 的 `SecItemAdd`、`SecItemCopyMatching`、`SecItemDelete` 等，参数较多，通常封装成工具类。
- **注意**：同一 key 的 kSecClass 要一致；查询时需指定 kSecReturnData、kSecMatchLimit 等。

配套示例中的 `KeychainHelper` 封装了保存、读取、删除，可直接复用。

### 5. 选型对比

| 场景 | 推荐方式 |
|------|----------|
| 用户设置、开关、简单配置 | NSUserDefaults |
| 密码、token、敏感信息 | Keychain |
| 用户文档、导出文件 | Documents + 文件 API |
| 图片/数据缓存、可重建内容 | Caches + 文件 API |
| 临时计算中间结果 | tmp |

## 注意事项 / 常见坑

- **Documents 与 Caches**：不要将可重新下载的大文件放在 Documents，否则备份慢且可能被拒审；应放 Caches。
- **NSUserDefaults**：不要存大量数据或复杂对象图；自定义对象需转成 plist 兼容类型（或归档为 Data）。
- **Keychain**：identifier 建议用 bundleId + 业务 key，避免与其他应用冲突；模拟器与真机行为一致，但备份/恢复时需注意 kSecAttrAccessible。

## 小结

- 沙盒三块：Documents（用户数据）、Caches（缓存）、tmp（临时）。
- NSUserDefaults 做轻量配置；敏感数据用 Keychain。
- 文件读写用 NSFileManager / NSData，注意选对目录与是否备份。
