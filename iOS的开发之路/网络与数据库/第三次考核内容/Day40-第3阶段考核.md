# Day 40：第3阶段考核

## 概述

本文档对**第3阶段：数据持久化与网络编程**做知识回顾，并给出考核形式建议与常见考点、自测要点。配套示例路径汇总见文末，便于考前对照练习。

## 本阶段知识回顾

### 1. 本地存储（Day 30-31）

- **沙盒**：Documents（用户数据，备份）、Caches（缓存，不备份）、tmp（临时）。
- **NSFileManager**：路径获取、创建目录、读写文件。
- **NSUserDefaults**：轻量键值对，适合配置；注意不要存大量数据。
- **Keychain**：敏感信息（密码、token），Security.framework，SecItemAdd/SecItemCopyMatching/SecItemDelete。
- **选型**：配置用 UserDefaults，敏感用 Keychain，文件用沙盒+文件 API。

### 2. 数据库基础（Day 32-33）

- **SQLite**：文件型数据库，内置 iOS。
- **FMDB**：FMDatabase（单线程）、FMDatabaseQueue（多线程安全）、事务（beginTransaction/commit/rollback）。
- **SQL**：建表、INSERT/UPDATE/DELETE/SELECT，参数化防注入。

### 3. 数据库设计与优化（Day 34）

- **设计**：主键、索引、范式与反范式。
- **优化**：按需 SELECT、WHERE 用索引列、大批量用事务、迁移用版本号与 ALTER/重建表。

### 4. HTTP/HTTPS（Day 35）

- **HTTP**：请求/响应结构、GET/POST、状态码、常用 Header。
- **HTTPS**：TLS、证书校验；NSURLSession 默认校验。
- **NSURLSession**：dataTaskWithRequest、completionHandler 中处理 Data 与 NSHTTPURLResponse。

### 5. AFNetworking（Day 36）

- **架构**：基于 NSURLSession，AFHTTPSessionManager、requestSerializer、responseSerializer。
- **封装**：BaseURL、通用 Header、超时、统一错误与状态码处理、GET/POST 封装。

### 6. 网络数据处理（Day 37-38）

- **断点续传**：Range、NSURLSessionDownloadTask、resumeData 保存与恢复。
- **上传**：multipart/form-data、NSURLSessionUploadTask 或 AF 的 constructingBodyWithBlock。
- **下载**：DownloadTask 完成后移动文件到 Caches/Documents。
- **JSON**：NSJSONSerialization、字典转模型思路。

### 7. 网络层架构（Day 39）

- **分层**：API 层（path、method）、业务层（调用与解析）、数据层（实际发请求）。
- **统一**：请求封装、响应格式、错误码与错误提示；可扩展（新接口、多环境）。

## 考核形式建议

- **理论题**：选择题/简答题，覆盖上述知识点（沙盒目录、Keychain 用途、FMDB 线程安全、HTTP 状态码、断点续传原理、网络层分层等）。
- **实操题**：在现有工程或新建工程中实现一项或多项，例如：用 NSUserDefaults 存配置、用 Keychain 存 token、用 FMDB 建表并查询、用 NSURLSession 或 AFNetworking 发 GET/POST 并解析 JSON、实现一个简单断点续传或文件上传。

## 常见考点与自测要点

| 考点 | 自测要点 |
|------|----------|
| 沙盒 | 能说出 Documents/Caches/tmp 区别与是否备份；会取路径。 |
| NSUserDefaults | 会存取；知道适用场景与限制。 |
| Keychain | 会使用封装类或 Security API 存/取/删；知道用途。 |
| SQLite/FMDB | 会建表、增删改查、事务、FMDatabaseQueue。 |
| 数据库优化 | 知道主键、索引、迁移基本思路。 |
| HTTP/HTTPS | 知道请求结构、GET/POST、常见状态码；NSURLSession 发请求。 |
| AFNetworking | 知道 AFHTTPSessionManager、封装要点。 |
| 断点续传 | 知道 resumeData、取消时保存、恢复下载。 |
| 上传/下载 | multipart 上传、下载到沙盒并保存路径。 |
| JSON | NSJSONSerialization 解析；字典转模型。 |
| 网络层 | 分层、统一请求与错误处理、可扩展。 |
