**需要的知识**

 1. CPU和GPU的区别：

	 - CPU更擅长逻辑判断问题，

	 - GPU更擅长：

        - 渲染

        - 运算能力 -> 音视频解码/ 视频滤镜，特效处理/机器学习

 2. 显示器成像的原理（几代显示器的变化）

	 - 第一代：随机扫描显示（只能绘制路径，不能显示图形）

	 - 第二代：光栅显示器：使用****单一帧缓冲区****存储器像素画图像，颜色用RGB通道计算

        - 缺点：因为是横向从上到下扫描，所以在面对复杂图像时会导致屏幕撕裂(上半部分是旧的位图数据，下半部分是更新后的帧缓存区数据）

        - 解决方法：

            -1.双缓存区：采用****两个缓冲区**** 分别把上一帧和下一帧的数据放在不同的两个缓冲区，依此进行交换，就不会在一个缓冲区里出现两种结果

            -2.垂直同步：；使用垂直同步信号，直到整个图形打印完毕才刷新

            - 新问题：掉帧：当上一帧还没加载出来的时候还是显示上一帧的内容，就会导致掉帧
	            - 解决方法：三缓冲区：**只能减少掉帧** （苹果没有用这种方案，这是一种优化策略）
3.  **渲染的流程（渲染的本质）：** 
	CPU -> **顶点着色器**（确定图形具体在硬件显示位置的转化；平移/缩放/旋转；2D ->3D；特效）/**片元着色器**（计算咩一个像素点的颜色）->光栅化（GPU Rasterization）->把结果放在**帧缓冲区** 
	-> 由显示系统把结果放在显示屏幕里
4. **苹果的图形渲染架构（自顶向下）**
	1.  UIKit/APPKit（最顶层）
	2. Core Animation
	3. （Metal/OPenGLES） && （core Graphics）
	4. Graphics Hardware（最底层）
5. 离屏渲染本质：
	1. 图形太复杂，没办法一下子做完，就需要开辟一个离屏渲染缓冲区。等到所有的离屏缓冲区内容都做好以后，就把合并的内容存在帧缓冲区。（例如：毛玻璃效果）
	2. 主动打开光栅化（shouldRasterize=YES；），当不得不用离屏渲染的内容，且存在复用的layer（复用就是有多个图层layer或者毛玻璃效果），就可以打开光栅化，但是打开这个选项需要注意以下问题：
		   1. layer不能复用，则没必要打开
		   2. layer不是静态的，不哟打开，要不然反而会影响效率
		   3. 缓存内容100ms的内容没有被使用就会被丢弃，无法被复用
		   4. 离屏渲染缓存空间有限，超过2.5倍屏幕大小的话也会失效，且无法复用
	   3. **为什么有时候圆角会触发离屏，有时候不会？**
		   1. 你的图片如果有背景有图片等，就相当于不是只一个图层，单独讲其中的一个圆角是不会触发离屏渲染的，只有在三个layer都离屏的时候才会触发
		   2. **来点苹果原话**：当给定radius 超过0.0 会导致图层（layer）开始在**其背景**中绘制圆角。默认下，圆角半径不会应用到图层的内容属性的图像中；它只会应用到其背景和自身的边界线中。因此，将`maskToBounds`设置成`YES`，会导致内容切成圆角。
		   3. 也就是说：
			- 设置 cornerRadius 不会渲染该图层的内容图像
			- 设置 corner Radius 只会渲染 layer 的边框及背景
			- 属性 maskToBounds 设置YES，会切成圆角
		
6. **触发离屏渲染的情况** 
	1. 使用了mask的layer（layer.mask)
	2. 需要进行裁剪的layer（layer.maskToBounds /View.clipsToBounds)
	3. 设置了组透明度为YES，并且透明度不为1的layer（layer.allowGroupOpacity/layer.opacity)
	4. 采用了投影的layer(layer.shadow *)
	5. 采用了光栅化的layer（layer.shouldRasteriaze)
	6. 绘制了文字的layer(UILabel,CATextLayer,Core Text等)
7. **怎么优化？** 
	1. AsyncDisplayKit第三方库优化
	2. 对图片进行圆角化预处理
	3. 视频圆角->添加一个图层盖住
	4. 如果图片没有背景颜色->用cornerRadius
	5. 所有的阴影 ，用shadowPath
	6. 必须要用mask的时候，复用打开shouldRasterize
	7. 模糊效果手动渲染
