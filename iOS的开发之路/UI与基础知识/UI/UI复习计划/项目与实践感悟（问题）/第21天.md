目前今日头条的设计架构：
定义了基类BaseViewController作为所有controller的初始化模版，方便后期统一设置各种类型的颜色变动，刷新等

![[截屏2026-01-16 18.19.49.png]]
首页效果：最底层是一层UIView（HOmeViewController继承自BaseViewController（UIViewController）），然后先将背景图backgroundView放进HomeViewController，然后声明一个MenuTab，声明一个ScrollerView为contetnview，在里面放入横向列表数据，定义channels，并根据channelname设置不同的几个按钮，并设置子控制器，，将每一个不同的channels里面的设置不同数据加载和数据类型，并将子控制器的VC加入scrollerView中，同时设置代理给按钮，让他们可以响应点击，检测到点击后可以跳转对应频道，

然后设置基类Cells：GTNewsTableViewCell，负责提供给Home界面上的不同cells一个基本的加载View框架，同时在原本的新闻model（GTnewsitem）中加入CellTp的选项，来装一个枚举数组类型的celltype![[截屏2026-01-16 18.39.01.png]]
然后在GTNewListViewController里面（这个是定义全局的纵向滚动的TableView）因为涉及到注册cell的内容，所以需要写if语句判断一下用哪个
![[截屏2026-01-16 18.42.21.png]]
然后tableview的datasource就只需要根据celltp的类型返回就好了，这样就实现了一张列表点击不同的子控制器跳转出来不同的cell样式！
