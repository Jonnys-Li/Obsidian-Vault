## 2. Cell 重用机制

  

### 2.1 重用机制原理

  

UITableView 使用**重用池（Reuse Pool）**机制来优化内存和性能：

  

1. **出队（Dequeue）**：从重用池中取出可复用的 Cell

2. **配置数据**：更新 Cell 的内容

3. **入队（Enqueue）**：Cell 移出屏幕时，放回重用池

  

### 2.2 代码实现

  

```objc 121:131:ContactMenu/LBWTableViewCOntroller.m

- (UITableViewCell *)tableView:(UITableView *)tableView cellForRowAtIndexPath:(NSIndexPath *)indexPath {

// 使用 viewDidLoad 中注册的 "contact"

LBWContactCellTableViewCell *cell = [tableView dequeueReusableCellWithIdentifier:@"contact" forIndexPath:indexPath];

// 优化 2：添加右侧系统箭头

cell.accessoryType = UITableViewCellAccessoryDisclosureIndicator;

// 获取对应的联系人模型

LBWContact *contact = self.groups[indexPath.section].contacts[indexPath.row];

// 设置 contact 属性，这样会触发 setContact: 方法，更新头像和首字母

cell.contact = contact;

return cell;

}

```

  

**关键方法：**

- `dequeueReusableCellWithIdentifier:forIndexPath:` - 从重用池获取 Cell，如果池中没有则自动创建

  

**⚠️ 注意事项：**

- 必须在 `viewDidLoad` 中先注册 Cell 类

- 每次出队后必须重新设置数据，因为 Cell 可能被其他行复用

_contact = contact;

self.nameLabel.text = contact.name;

self.phoneLabel.text = contact.phoneNumber;

### 3.5 彩色头像实现

  

根据联系人姓名生成唯一颜色：

  

```objc 85:90:ContactMenu/LBWContactCellTableViewCell.m

- (UIColor *)colorFromName:(NSString *)name {

if (name.length == 0) return [UIColor lightGrayColor];

// 使用名字的hash值生成颜色，确保相同名字总是相同颜色

NSUInteger hash = [name hash];

// 将hash值转换为0-1之间的hue值，使用绝对值确保为正数

CGFloat hue = fabs((hash % 360) / 360.0);

// 使用较高的饱和度和亮度，让颜色更鲜艳

return [UIColor colorWithHue:hue saturation:0.7 brightness:0.85 alpha:1.0];

}

```

  

**实现要点：**

- 使用 `hash` 值确保相同名字生成相同颜色

- 使用 HSL 颜色空间，通过 `hue` 值生成不同颜色

- 首字母 Label 添加到 `iconView` 上，实现文字居中显示

### 4.3 数据排序与分组

  

使用 `UILocalizedIndexedCollation` 实现自动分组和排序：

  

```objc 68:104:ContactMenu/LBWTableViewCOntroller.m

// 2. 获取系统的排序工具 (自动处理拼音和 A-Z)

UILocalizedIndexedCollation *collation = [UILocalizedIndexedCollation currentCollation];

// 3. 获取系统支持的所有索引标题数量 (A-Z...#)

NSInteger sectionCount = [[collation sectionTitles] count];

NSMutableArray *newSectionsArray = [NSMutableArray arrayWithCapacity:sectionCount];

// 为每个可能的索引创建一个临时数组

for (int i = 0; i < sectionCount; i++) {

[newSectionsArray addObject:[NSMutableArray array]];

}

  

// 4. 分组：把联系人按首字母放进对应的数组容器

for (LBWContact *contact in allContacts) {

// 自动计算该名字应该属于哪个 section

NSInteger sectionNumber = [collation sectionForObject:contact collationStringSelector:@selector(name)];

[newSectionsArray[sectionNumber] addObject:contact];

}

  

// 5. 封装成 Model 数组，并剔除掉没有任何人的空组

NSMutableArray *finalGroups = [NSMutableArray array];

for (int i = 0; i < sectionCount; i++) {

NSMutableArray *tempArray = newSectionsArray[i];

if (tempArray.count > 0) {

// 对每组内部进行 A-Z 排序（防止同字母组内乱序）

NSArray *sortedArray = [collation sortedArrayFromArray:tempArray collationStringSelector:@selector(name)];

LBWContactGroup *group = [[LBWContactGroup alloc] init];

group.title = [collation sectionTitles][i];

group.contacts = sortedArray;

[finalGroups addObject:group];

}

}

// 将处理好的数据赋值给全局变量

self.groups = finalGroups;

[self.tableView reloadData];

```

  

**优势：**

- 自动处理中文拼音排序

- 自动处理英文 A-Z 排序

- 自动生成索引标题

## 🐛 常见问题与解决方案

  

### 问题1：Cell 显示错误数据

  

**原因：** Cell 被复用时，没有重新设置数据

  

**解决：** 在 `cellForRowAtIndexPath:` 中必须重新设置所有数据

  

### 问题2：自定义 Cell 不显示

  

**原因：** 忘记注册 Cell 类或忘记设置 `cell.contact`

  

**解决：**

- 在 `viewDidLoad` 中注册：`registerClass:forCellReuseIdentifier:`

- 在 `cellForRowAtIndexPath:` 中设置：`cell.contact = contact;`

  

### 问题3：首字母和颜色不显示

  

**原因：** 只设置了 `cell.textLabel.text`，没有设置 `cell.contact`

  

**解决：** 使用 `cell.contact = contact;` 触发 `setContact:` 方法
