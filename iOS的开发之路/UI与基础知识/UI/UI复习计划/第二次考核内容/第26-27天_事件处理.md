# 第26-27天：事件处理（响应者链、手势识别）

## 核心知识点总结

### 1. 响应者链（Responder Chain）

#### 基本概念
- 响应者链是事件传递的路径
- 从第一响应者开始，向上传递到Window
- 每个响应者都有nextResponder属性

#### 响应者链路径
```
View → SuperView → ViewController → Window → Application
```

#### 响应者方法
- `touchesBegan:withEvent:` - 触摸开始
- `touchesMoved:withEvent:` - 触摸移动
- `touchesEnded:withEvent:` - 触摸结束
- `touchesCancelled:withEvent:` - 触摸取消

### 2. Hit-Test 机制

#### 基本概念
- 确定触摸事件发生在哪个视图上
- 使用`hitTest:withEvent:`方法
- 使用`pointInside:withEvent:`判断点是否在视图内

#### 查找流程
1. 从Window开始，向下查找
2. 调用`pointInside:withEvent:`判断点是否在视图内
3. 如果在，递归查找子视图
4. 返回最上层的包含该点的视图

#### 自定义Hit-Test
```objc
- (UIView *)hitTest:(CGPoint)point withEvent:(UIEvent *)event {
    // 扩大点击区域
    CGRect expandedBounds = CGRectInset(self.bounds, -20, -20);
    if (CGRectContainsPoint(expandedBounds, point)) {
        return self;
    }
    return [super hitTest:point withEvent:event];
}
```

### 3. 事件传递流程

#### 传递阶段（Hit-Testing）
1. 系统确定触摸点所在的视图
2. 从Window开始，向下查找
3. 返回最上层的视图作为第一响应者

#### 响应阶段（Responder Chain）
1. 从第一响应者开始
2. 如果第一响应者不处理，传递给nextResponder
3. 沿着响应者链向上传递
4. 如果都不处理，事件被丢弃

### 4. 手势识别（UIGestureRecognizer）

#### 常用手势类型
- `UITapGestureRecognizer` - 点击手势
- `UIPanGestureRecognizer` - 拖动手势
- `UIPinchGestureRecognizer` - 缩放手势
- `UIRotationGestureRecognizer` - 旋转手势
- `UILongPressGestureRecognizer` - 长按手势
- `UISwipeGestureRecognizer` - 滑动手势

#### 手势状态
- `UIGestureRecognizerStatePossible` - 可能
- `UIGestureRecognizerStateBegan` - 开始
- `UIGestureRecognizerStateChanged` - 改变
- `UIGestureRecognizerStateEnded` - 结束
- `UIGestureRecognizerStateCancelled` - 取消
- `UIGestureRecognizerStateFailed` - 失败

#### 手势代理
- `UIGestureRecognizerDelegate` - 手势代理协议
- `gestureRecognizer:shouldReceiveTouch:` - 是否接收触摸
- `gestureRecognizer:shouldRecognizeSimultaneouslyWithGestureRecognizer:` - 是否同时识别

### 5. 手势冲突处理

#### 冲突场景
- 多个手势同时识别
- 手势与ScrollView冲突
- 手势优先级问题

#### 解决方法
- 使用代理方法控制手势识别
- 设置手势依赖关系
- 设置手势优先级
- 使用`requireGestureRecognizerToFail:`

```
View → SuperView → ViewController → Window → Application
```

### 进阶题

#### 5. 如何自定义Hit-Test扩大点击区域？

**答案：**
```objc
- (UIView *)hitTest:(CGPoint)point withEvent:(UIEvent *)event {
    // 扩大点击区域
    CGRect expandedBounds = CGRectInset(self.bounds, -20, -20);
    
    // 判断点是否在扩大后的区域内
    if (CGRectContainsPoint(expandedBounds, point)) {
        // 检查子视图
        for (UIView *subview in [self.subviews reverseObjectEnumerator]) {
            CGPoint convertedPoint = [self convertPoint:point toView:subview];
            UIView *hitView = [subview hitTest:convertedPoint withEvent:event];
            if (hitView) {
                return hitView;
            }
        }
        return self;
    }
    
    return nil;
}
```

#### 6. 如何解决手势冲突？

**答案：**
1. **使用代理方法**：
```objc
- (BOOL)gestureRecognizer:(UIGestureRecognizer *)gestureRecognizer 
shouldRecognizeSimultaneouslyWithGestureRecognizer:(UIGestureRecognizer *)otherGestureRecognizer {
    return YES; // 允许同时识别
}
```

2. **设置依赖关系**：
```objc
[gesture1 requireGestureRecognizerToFail:gesture2];
// gesture1只有在gesture2失败时才会识别
```

3. **设置优先级**：
```objc
gesture1.priority = 1000;
gesture2.priority = 500;
```

#### 7. 手势与ScrollView冲突如何解决？

**答案：**
1. **使用代理方法控制**：
```objc
- (BOOL)gestureRecognizer:(UIGestureRecognizer *)gestureRecognizer 
shouldRecognizeSimultaneouslyWithGestureRecognizer:(UIGestureRecognizer *)otherGestureRecognizer {
    if ([otherGestureRecognizer.view isKindOfClass:[UIScrollView class]]) {
        return YES;
    }
    return NO;
}
```

2. **设置依赖关系**：
```objc
[panGesture requireGestureRecognizerToFail:scrollView.panGestureRecognizer];
```

3. **禁用ScrollView手势**：
```objc
scrollView.panGestureRecognizer.enabled = NO;
```

#### 8. 如何实现自定义手势识别器？

**答案：**
1. 继承`UIGestureRecognizer`
2. 重写关键方法：
```objc
- (void)touchesBegan:(NSSet<UITouch *> *)touches withEvent:(UIEvent *)event {
    // 判断是否满足手势条件
    if (满足条件) {
        self.state = UIGestureRecognizerStateBegan;
    } else {
        self.state = UIGestureRecognizerStateFailed;
    }
}

- (void)touchesMoved:(NSSet<UITouch *> *)touches withEvent:(UIEvent *)event {
    if (self.state == UIGestureRecognizerStateBegan) {
        // 更新手势状态
        self.state = UIGestureRecognizerStateChanged;
    }
}

- (void)touchesEnded:(NSSet<UITouch *> *)touches withEvent:(UIEvent *)event {
    if (self.state == UIGestureRecognizerStateChanged) {
        self.state = UIGestureRecognizerStateEnded;
    }
}
```

### 原理题

#### 9. 响应者链的查找原理是什么？

**答案：**
1. **Hit-Testing阶段**：
   - 从Window开始，向下查找
   - 调用`pointInside:withEvent:`判断点是否在视图内
   - 如果在，递归查找子视图
   - 返回最上层的包含该点的视图
   
2. **响应阶段**：
   - 从第一响应者开始
   - 如果第一响应者不处理，传递给nextResponder
   - 沿着响应者链向上传递
   - 如果都不处理，事件被丢弃

#### 10. 手势识别器的工作原理是什么？

**答案：**
1. **触摸事件接收**：
   - 手势识别器接收触摸事件
   - 分析触摸轨迹
   
2. **状态转换**：
   - `Possible` → `Began` → `Changed` → `Ended`
   - 如果不符合手势条件，转换为`Failed`或`Cancelled`
   
3. **代理方法**：
   - 通过代理方法控制手势识别
   - 可以阻止或允许手势识别
   
4. **冲突处理**：
   - 通过依赖关系和优先级解决冲突
   - 使用代理方法控制同时识别

### 实操题1：实现自定义Hit-Test扩大点击区域

#### 需求描述
创建一个按钮，扩大点击区域但不改变视觉大小。

#### 实现步骤

1. **创建自定义视图**
```objc
// CustomHitTestView.h
@interface CustomHitTestView : UIView
@end

// CustomHitTestView.m
@implementation CustomHitTestView

- (UIView *)hitTest:(CGPoint)point withEvent:(UIEvent *)event {
    // 扩大点击区域（上下左右各扩大20点）
    CGRect expandedBounds = CGRectInset(self.bounds, -20, -20);
    
    // 判断点是否在扩大后的区域内
    if (CGRectContainsPoint(expandedBounds, point)) {
        // 先检查子视图
        for (UIView *subview in [self.subviews reverseObjectEnumerator]) {
            CGPoint convertedPoint = [self convertPoint:point toView:subview];
            UIView *hitView = [subview hitTest:convertedPoint withEvent:event];
            if (hitView) {
                return hitView;
            }
        }
        // 如果没有子视图响应，返回自己
        return self;
    }
    
    // 点不在扩大后的区域内，返回nil
    return nil;
}

- (BOOL)pointInside:(CGPoint)point withEvent:(UIEvent *)event {
    // 扩大点击区域
    CGRect expandedBounds = CGRectInset(self.bounds, -20, -20);
    return CGRectContainsPoint(expandedBounds, point);
}

@end
```

2. **使用自定义视图**
```objc
- (void)setupCustomHitTestView {
    CustomHitTestView *view = [[CustomHitTestView alloc] initWithFrame:CGRectMake(100, 100, 100, 100)];
    view.backgroundColor = [UIColor blueColor];
    
    // 添加点击手势
    UITapGestureRecognizer *tap = [[UITapGestureRecognizer alloc] initWithTarget:self action:@selector(handleTap:)];
    [view addGestureRecognizer:tap];
    
    [self.view addSubview:view];
}

- (void)handleTap:(UITapGestureRecognizer *)gesture {
    NSLog(@"点击了视图，即使点击区域在视觉范围外也能响应");
}
```

#### 关键代码

```objc
// 只扩大特定方向的点击区域
- (UIView *)hitTest:(CGPoint)point withEvent:(UIEvent *)event {
    // 只扩大上下方向的点击区域
    CGRect expandedBounds = CGRectMake(self.bounds.origin.x,
                                       self.bounds.origin.y - 20,
                                       self.bounds.size.width,
                                       self.bounds.size.height + 40);
```

### 实操题2：实现多种手势识别

#### 需求描述
创建一个界面，包含多种手势识别器，演示各种手势的使用。

#### 实现步骤

1. **点击手势**
```objc
- (void)setupTapGesture {
    UITapGestureRecognizer *tap = [[UITapGestureRecognizer alloc] initWithTarget:self action:@selector(handleTap:)];
    tap.numberOfTapsRequired = 1; // 单击
    tap.numberOfTouchesRequired = 1; // 单指
    [self.targetView addGestureRecognizer:tap];
}

- (void)handleTap:(UITapGestureRecognizer *)gesture {
    NSLog(@"点击手势");
}
```

2. **拖动手势**
```objc
- (void)setupPanGesture {
    UIPanGestureRecognizer *pan = [[UIPanGestureRecognizer alloc] initWithTarget:self action:@selector(handlePan:)];
    [self.targetView addGestureRecognizer:pan];
}

- (void)handlePan:(UIPanGestureRecognizer *)gesture {
    CGPoint translation = [gesture translationInView:self.view];
    
    switch (gesture.state) {
        case UIGestureRecognizerStateBegan:
            NSLog(@"拖动手势开始");
            break;
        case UIGestureRecognizerStateChanged:
            // 移动视图
            self.targetView.center = CGPointMake(self.targetView.center.x + translation.x,
                                                self.targetView.center.y + translation.y);
            [gesture setTranslation:CGPointZero inView:self.view];
            break;
        case UIGestureRecognizerStateEnded:
            NSLog(@"拖动手势结束");
            break;
        default:
            break;
    }
}
```

3. **缩放手势**
```objc
- (void)setupPinchGesture {
    UIPinchGestureRecognizer *pinch = [[UIPinchGestureRecognizer alloc] initWithTarget:self action:@selector(handlePinch:)];
    [self.targetView addGestureRecognizer:pinch];
}

- (void)handlePinch:(UIPinchGestureRecognizer *)gesture {
    if (gesture.state == UIGestureRecognizerStateChanged) {
        CGFloat scale = gesture.scale;
        self.targetView.transform = CGAffineTransformMakeScale(scale, scale);
    }
}
```

4. **旋转手势**
```objc
- (void)setupRotationGesture {
    UIRotationGestureRecognizer *rotation = [[UIRotationGestureRecognizer alloc] initWithTarget:self action:@selector(handleRotation:)];
    [self.targetView addGestureRecognizer:rotation];
}

- (void)handleRotation:(UIRotationGestureRecognizer *)gesture {
    if (gesture.state == UIGestureRecognizerStateChanged) {
        CGFloat rotation = gesture.rotation;
        self.targetView.transform = CGAffineTransformRotate(self.targetView.transform, rotation);
        gesture.rotation = 0;
    }
}
```

#### 关键代码

```objc
// 同时支持缩放和旋转
- (void)setupMultipleGestures {
    UIPinchGestureRecognizer *pinch = [[UIPinchGestureRecognizer alloc] initWithTarget:self action:@selector(handlePinch:)];
    UIRotationGestureRecognizer *rotation = [[UIRotationGestureRecognizer alloc] initWithTarget:self action:@selector(handleRotation:)];
    
    // 设置代理，允许同时识别
    pinch.delegate = self;
    rotation.delegate = self;
    
    [self.targetView addGestureRecognizer:pinch];
    [self.targetView addGestureRecognizer:rotation];
}

- (BOOL)gestureRecognizer:(UIGestureRecognizer *)gestureRecognizer 
shouldRecognizeSimultaneouslyWithGestureRecognizer:(UIGestureRecognizer *)otherGestureRecognizer {
    return YES; // 允许同时识别
}
```

### 实操题3：解决手势冲突

#### 需求描述
创建一个界面，演示如何解决多个手势的冲突问题。

#### 实现步骤

1. **设置手势依赖关系**
```objc
- (void)setupGestureDependencies {
    UITapGestureRecognizer *singleTap = [[UITapGestureRecognizer alloc] initWithTarget:self action:@selector(handleSingleTap:)];
    singleTap.numberOfTapsRequired = 1;
    
    UITapGestureRecognizer *doubleTap = [[UITapGestureRecognizer alloc] initWithTarget:self action:@selector(handleDoubleTap:)];
    doubleTap.numberOfTapsRequired = 2;
    
    // 单击手势只有在双击手势失败时才会识别
    [singleTap requireGestureRecognizerToFail:doubleTap];
    
    [self.targetView addGestureRecognizer:singleTap];
    [self.targetView addGestureRecognizer:doubleTap];
}
```

2. **解决手势与ScrollView冲突**
```objc
- (void)setupScrollViewGestureConflict {
    UIScrollView *scrollView = [[UIScrollView alloc] initWithFrame:self.view.bounds];
    [self.view addSubview:scrollView];
    
    UIView *contentView = [[UIView alloc] initWithFrame:CGRectMake(0, 0, 1000, 1000)];
    contentView.backgroundColor = [UIColor lightGrayColor];
    [scrollView addSubview:contentView];
    scrollView.contentSize = contentView.bounds.size;
    
    // 添加自定义手势
    UIPanGestureRecognizer *customPan = [[UIPanGestureRecognizer alloc] initWithTarget:self action:@selector(handleCustomPan:)];
    customPan.delegate = self;
    [contentView addGestureRecognizer:customPan];
    
    // 设置代理方法
    - (BOOL)gestureRecognizer:(UIGestureRecognizer *)gestureRecognizer 
shouldRecognizeSimultaneouslyWithGestureRecognizer:(UIGestureRecognizer *)otherGestureRecognizer {
        if ([otherGestureRecognizer.view isKindOfClass:[UIScrollView class]]) {
            return YES; // 允许与ScrollView同时识别
        }
        return NO;
    }
}
```

3. **使用手势优先级**
```objc
- (void)setupGesturePriority {
    UIPanGestureRecognizer *pan1 = [[UIPanGestureRecognizer alloc] initWithTarget:self action:@selector(handlePan1:)];
    UIPanGestureRecognizer *pan2 = [[UIPanGestureRecognizer alloc] initWithTarget:self action:@selector(handlePan2:)];
    
    // 设置优先级（通过依赖关系）
    [pan2 requireGestureRecognizerToFail:pan1];
    
    [self.targetView addGestureRecognizer:pan1];
    [self.targetView addGestureRecognizer:pan2];
}
```

```objc
@end

    }

        [otherGestureRecognizer isKindOfClass:[UIRotationGestureRecognizer class]]) {
        return YES;
    }
    return NO;
}

@end
```
