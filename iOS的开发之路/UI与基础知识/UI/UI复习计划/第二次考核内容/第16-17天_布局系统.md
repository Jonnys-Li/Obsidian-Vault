# 第16-17天：布局系统（Frame、AutoLayout、Masonry）

## 核心知识点总结

### 1. Frame 布局

#### 基础概念
- Frame是视图的位置和大小
- Frame是相对于父视图的坐标系
- 使用CGRect结构体表示

#### 设置Frame
```objc
view.frame = CGRectMake(x, y, width, height);
// 或
view.frame = CGRectMake(0, 0, 100, 100);
```

#### 优点和缺点
- **优点**：简单直接，性能好
- **缺点**：需要手动计算位置，适配不同屏幕困难

### 2. AutoLayout 约束布局

#### 核心概念
- **约束（Constraint）**：描述视图之间的关系
- **约束方程**：`view1.attribute = multiplier × view2.attribute + constant`
- **优先级（Priority）**：约束的优先级，范围0-1000

#### 约束类型
- **位置约束**：leading、trailing、top、bottom、centerX、centerY
- **大小约束**：width、height
- **边距约束**：margin、spacing

#### 创建约束
```objc
// 使用NSLayoutConstraint
[NSLayoutConstraint constraintWithItem:view1 
                             attribute:NSLayoutAttributeLeading 
                             relatedBy:NSLayoutRelationEqual 
                                toItem:view2 
                             attribute:NSLayoutAttributeTrailing 
                            multiplier:1.0 
                              constant:10];
```

#### 激活约束
```objc
// iOS 9+
constraint.active = YES;

// iOS 8及之前
[NSLayoutConstraint activateConstraints:@[constraint1, constraint2]];
```

### 3. Masonry 布局框架

#### 简介
- 基于AutoLayout的链式语法封装
- 代码更简洁易读
- 自动处理translatesAutoresizingMaskIntoConstraints

#### 基本用法
```objc
[view mas_makeConstraints:^(MASConstraintMaker *make) {
    make.top.equalTo(superview.mas_top).offset(10);
    make.leading.equalTo(superview.mas_leading).offset(10);
    make.width.equalTo(@100);
    make.height.equalTo(@100);
}];
```

#### 常用方法
- `mas_makeConstraints:` - 创建约束
- `mas_updateConstraints:` - 更新约束
- `mas_remakeConstraints:` - 重新创建约束

## 面试题

### 基础题

#### 1. Frame布局和AutoLayout有什么区别？

**答案：**
- **Frame布局**：
  - 直接设置视图的位置和大小
  - 需要手动计算位置
  - 性能好，但适配困难
  
- **AutoLayout**：
  - 使用约束描述视图关系
  - 自动计算位置和大小
  - 适配方便，但性能稍差

#### 2. AutoLayout的约束方程是什么？

**答案：**
```
view1.attribute = multiplier × view2.attribute + constant
```

例如：
```
button.leading = 1.0 × superview.leading + 20
```
表示button的leading边距离superview的leading边20个点。

#### 3. 约束的优先级有什么作用？

**答案：**
- 优先级范围：0-1000
- 默认优先级：1000（必需约束）
- 当约束冲突时，系统会优先满足高优先级的约束
- 可以设置可选约束（优先级<1000），在空间不足时可以忽略

#### 4. Masonry的优势是什么？

**答案：**
- **链式语法**：代码更简洁易读
- **自动处理**：自动设置translatesAutoresizingMaskIntoConstraints = NO
- **更新方便**：提供update和remake方法
- **错误提示**：更好的错误信息

### 进阶题

#### 5. AutoLayout的性能问题如何优化？

**答案：**
1. **减少约束数量**：使用更少的约束描述布局
2. **避免深层嵌套**：减少视图层级
3. **使用intrinsicContentSize**：让系统自动计算大小
4. **缓存约束**：避免重复创建约束
5. **使用Frame布局**：对于简单布局，使用Frame性能更好

#### 6. 如何处理约束冲突？

**答案：**
1. **检查约束**：使用`hasAmbiguousLayout`检查
2. **设置优先级**：使用优先级解决冲突
3. **移除多余约束**：删除重复或冲突的约束
4. **使用约束组**：将相关约束组织在一起

```objc
// 检查约束冲突
if (view.hasAmbiguousLayout) {
    NSLog(@"约束冲突");
    [view exerciseAmbiguityInLayout];
}
```

#### 7. intrinsicContentSize 的作用是什么？

**答案：**
- 视图的固有内容大小
- 系统根据intrinsicContentSize自动计算约束
- UILabel、UIButton等控件都有intrinsicContentSize
- 可以重写`intrinsicContentSize`方法自定义

```objc
- (CGSize)intrinsicContentSize {
    return CGSizeMake(100, 44);
}
```

#### 8. 如何实现响应式布局？

**答案：**
1. **使用约束**：使用AutoLayout自动适配
2. **使用Size Classes**：适配不同设备
3. **监听屏幕旋转**：在`viewWillTransitionToSize:`中更新布局
4. **使用StackView**：简化布局代码

### 原理题

#### 9. AutoLayout的布局算法是什么？

**答案：**
AutoLayout使用Cassowary算法：
1. **约束收集**：收集所有约束
2. **约束求解**：使用线性规划求解约束系统
3. **布局计算**：计算每个视图的frame
4. **布局应用**：应用计算结果

**性能考虑**：
- 约束求解是O(n³)复杂度
- 约束越多，性能越差
- 系统会缓存计算结果

#### 10. translatesAutoresizingMaskIntoConstraints 的作用是什么？

**答案：**
- **作用**：将autoresizing mask转换为约束
- **默认值**：YES（使用Frame布局时）
- **AutoLayout时**：必须设置为NO
- **Masonry**：自动设置为NO

**原理**：
- 当设置为YES时，系统会将autoresizing mask转换为约束
- 这些约束可能与手动添加的约束冲突
- 所以使用AutoLayout时必须设置为NO

## 实操题

### 实操题1：实现Frame布局

#### 需求描述
使用Frame布局实现一个简单的界面，包含多个视图。

#### 实现步骤

1. **创建视图**
```objc
- (void)setupFrameLayout {
    // 创建红色视图
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    redView.frame = CGRectMake(20, 100, 100, 100);
    [self.view addSubview:redView];
    
    // 创建蓝色视图，在红色视图下方
    UIView *blueView = [[UIView alloc] init];
    blueView.backgroundColor = [UIColor blueColor];
    blueView.frame = CGRectMake(20, 220, 100, 100);
    [self.view addSubview:blueView];
    
    // 创建绿色视图，在红色视图右侧
    UIView *greenView = [[UIView alloc] init];
    greenView.backgroundColor = [UIColor greenColor];
    greenView.frame = CGRectMake(140, 100, 100, 100);
    [self.view addSubview:greenView];
}
```

2. **计算相对位置**
```objc
- (void)calculateRelativePosition {
    CGFloat screenWidth = self.view.bounds.size.width;
    CGFloat screenHeight = self.view.bounds.size.height;
    
    // 居中显示
    CGFloat viewWidth = 200;
    CGFloat viewHeight = 200;
    CGFloat x = (screenWidth - viewWidth) / 2;
    CGFloat y = (screenHeight - viewHeight) / 2;
    
    UIView *centerView = [[UIView alloc] init];
    centerView.backgroundColor = [UIColor yellowColor];
    centerView.frame = CGRectMake(x, y, viewWidth, viewHeight);
    [self.view addSubview:centerView];
}
```

#### 关键代码

```objc
// 适配不同屏幕
- (void)adaptToScreen {
    CGFloat screenWidth = self.view.bounds.size.width;
    
    // 根据屏幕宽度调整
    CGFloat viewWidth = screenWidth - 40; // 左右各20的边距
    CGFloat viewHeight = 100;
    
    UIView *adaptiveView = [[UIView alloc] init];
    adaptiveView.backgroundColor = [UIColor purpleColor];
    adaptiveView.frame = CGRectMake(20, 100, viewWidth, viewHeight);
    [self.view addSubview:adaptiveView];
}
```

#### 性能优化点
- Frame布局性能好，适合简单布局
- 避免频繁计算frame
- 缓存计算结果

### 实操题2：实现AutoLayout代码布局

#### 需求描述
使用AutoLayout实现相同的布局，对比Frame布局。

#### 实现步骤

1. **创建约束**
```objc
- (void)setupAutoLayout {
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    redView.translatesAutoresizingMaskIntoConstraints = NO;
    [self.view addSubview:redView];
    
    // 创建约束
    [NSLayoutConstraint activateConstraints:@[
        // 位置约束
        [redView.leadingAnchor constraintEqualToAnchor:self.view.leadingAnchor constant:20],
        [redView.topAnchor constraintEqualToAnchor:self.view.topAnchor constant:100],
        // 大小约束
        [redView.widthAnchor constraintEqualToConstant:100],
        [redView.heightAnchor constraintEqualToConstant:100]
    ]];
}
```

2. **使用Visual Format Language**
```objc
- (void)setupWithVFL {
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    redView.translatesAutoresizingMaskIntoConstraints = NO;
    [self.view addSubview:redView];
    
    NSDictionary *views = @{@"redView": redView};
    NSDictionary *metrics = @{@"margin": @20, @"size": @100};
    
    [NSLayoutConstraint activateConstraints:
     [NSLayoutConstraint constraintsWithVisualFormat:@"H:|-margin-[redView(size)]"
                                             options:0
                                             metrics:metrics
                                               views:views]];
    
    [NSLayoutConstraint activateConstraints:
     [NSLayoutConstraint constraintsWithVisualFormat:@"V:|-100-[redView(size)]"
                                             options:0
                                             metrics:metrics
                                               views:views]];
}
```

#### 关键代码

```objc
// 相对布局
- (void)setupRelativeLayout {
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    redView.translatesAutoresizingMaskIntoConstraints = NO;
    [self.view addSubview:redView];
    
    UIView *blueView = [[UIView alloc] init];
    blueView.backgroundColor = [UIColor blueColor];
    blueView.translatesAutoresizingMaskIntoConstraints = NO;
    [self.view addSubview:blueView];
    
    [NSLayoutConstraint activateConstraints:@[
        // redView约束
        [redView.leadingAnchor constraintEqualToAnchor:self.view.leadingAnchor constant:20],
        [redView.topAnchor constraintEqualToAnchor:self.view.topAnchor constant:100],
        [redView.widthAnchor constraintEqualToConstant:100],
        [redView.heightAnchor constraintEqualToConstant:100],
        
        // blueView约束（在redView下方）
        [blueView.leadingAnchor constraintEqualToAnchor:redView.leadingAnchor],
        [blueView.topAnchor constraintEqualToAnchor:redView.bottomAnchor constant:20],
        [blueView.widthAnchor constraintEqualToAnchor:redView.widthAnchor],
        [blueView.heightAnchor constraintEqualToAnchor:redView.heightAnchor]
    ]];
}
```

#### 性能优化点
- 减少约束数量
- 避免深层嵌套
- 使用intrinsicContentSize
- 缓存约束对象

### 实操题3：使用Masonry实现布局

#### 需求描述
使用Masonry实现布局，对比AutoLayout代码。

#### 实现步骤

1. **安装Masonry**
```ruby
# Podfile
pod 'Masonry'
```

2. **使用Masonry布局**
```objc
#import <Masonry/Masonry.h>

- (void)setupMasonryLayout {
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    [self.view addSubview:redView];
    
    [redView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.leading.equalTo(self.view).offset(20);
        make.top.equalTo(self.view).offset(100);
        make.width.equalTo(@100);
        make.height.equalTo(@100);
    }];
}
```

3. **相对布局**
```objc
- (void)setupRelativeMasonryLayout {
    UIView *redView = [[UIView alloc] init];
    redView.backgroundColor = [UIColor redColor];
    [self.view addSubview:redView];
    
    UIView *blueView = [[UIView alloc] init];
    blueView.backgroundColor = [UIColor blueColor];
    [self.view addSubview:blueView];
    
    [redView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.leading.equalTo(self.view).offset(20);
        make.top.equalTo(self.view).offset(100);
        make.width.equalTo(@100);
        make.height.equalTo(@100);
    }];
    
    [blueView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.leading.equalTo(redView);
        make.top.equalTo(redView.mas_bottom).offset(20);
        make.width.equalTo(redView);
        make.height.equalTo(redView);
    }];
}
```

#### 关键代码

```objc
// 更新约束
- (void)updateConstraints {
    [self.redView mas_updateConstraints:^(MASConstraintMaker *make) {
        make.width.equalTo(@200); // 更新宽度
    }];
    
    [UIView animateWithDuration:0.3 animations:^{
        [self.view layoutIfNeeded];
    }];
}

// 重新创建约束
- (void)remakeConstraints {
    [self.redView mas_remakeConstraints:^(MASConstraintMaker *make) {
        make.center.equalTo(self.view);
        make.size.equalTo(@100);
    }];
}
```

#### 性能优化点
- Masonry基于AutoLayout，性能特性相同
- 使用update而不是remake（如果可能）
- 避免在循环中创建约束

## 常见问题

### Q1: 什么时候使用Frame布局，什么时候使用AutoLayout？

**A:**
- **Frame布局**：简单布局，性能要求高，不需要适配
- **AutoLayout**：复杂布局，需要适配不同屏幕，响应式布局

### Q2: AutoLayout性能差怎么办？

**A:**
- 减少约束数量
- 避免深层嵌套
- 使用intrinsicContentSize
- 对于简单布局，使用Frame

### Q3: 约束冲突如何解决？

**A:**
- 检查约束，找出冲突的约束
- 设置优先级
- 移除多余约束
- 使用约束组

### Q4: Masonry和AutoLayout有什么区别？

**A:**
- Masonry是AutoLayout的封装
- 语法更简洁
- 性能相同
- 需要引入第三方库
