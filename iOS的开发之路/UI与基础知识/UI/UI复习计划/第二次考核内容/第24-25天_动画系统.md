# 第24-25天：动画系统（UIView Animation、Core Animation）

## 核心知识点总结

### 1. UIView Animation

#### 基础动画
```objc
[UIView animateWithDuration:0.3 animations:^{
    // 动画代码
    view.alpha = 0.5;
    view.frame = CGRectMake(100, 100, 200, 200);
}];
```

#### 带动画完成回调
```objc
[UIView animateWithDuration:0.3 animations:^{
    view.alpha = 0.5;
} completion:^(BOOL finished) {
    // 动画完成后的操作
}];
```

#### 动画选项
```objc
[UIView animateWithDuration:0.3 
                      delay:0 
                    options:UIViewAnimationOptionCurveEaseInOut 
                 animations:^{
    view.alpha = 0.5;
} completion:nil];
```

常用选项：
- `UIViewAnimationOptionCurveEaseInOut` - 缓入缓出
- `UIViewAnimationOptionCurveEaseIn` - 缓入
- `UIViewAnimationOptionCurveEaseOut` - 缓出
- `UIViewAnimationOptionCurveLinear` - 线性
- `UIViewAnimationOptionRepeat` - 重复
- `UIViewAnimationOptionAutoreverse` - 自动反转

#### Spring动画
```objc
[UIView animateWithDuration:0.5 
                      delay:0 
     usingSpringWithDamping:0.7 
      initialSpringVelocity:0 
                    options:0 
                 animations:^{
    view.frame = CGRectMake(100, 100, 200, 200);
} completion:nil];
```

参数说明：
- `damping` - 阻尼系数（0-1），越小弹性越大
- `initialSpringVelocity` - 初始速度

### 2. Core Animation

#### CABasicAnimation（基础动画）
```objc
CABasicAnimation *animation = [CABasicAnimation animationWithKeyPath:@"transform.scale"];
animation.fromValue = @(1.0);
animation.toValue = @(1.5);
animation.duration = 0.3;
animation.fillMode = kCAFillModeForwards;
animation.removedOnCompletion = NO;
[layer addAnimation:animation forKey:@"scaleAnimation"];
```

常用KeyPath：
- `transform.scale` - 缩放
- `transform.rotation` - 旋转
- `transform.translation` - 位移
- `opacity` - 透明度
- `backgroundColor` - 背景色
- `position` - 位置
- `bounds` - 大小

#### CAKeyframeAnimation（关键帧动画）
```objc
CAKeyframeAnimation *animation = [CAKeyframeAnimation animationWithKeyPath:@"position"];
animation.values = @[
    [NSValue valueWithCGPoint:CGPointMake(100, 100)],
    [NSValue valueWithCGPoint:CGPointMake(200, 100)],
    [NSValue valueWithCGPoint:CGPointMake(200, 200)],
    [NSValue valueWithCGPoint:CGPointMake(100, 200)]
];
animation.duration = 2.0;
animation.repeatCount = HUGE_VALF;
[layer addAnimation:animation forKey:@"pathAnimation"];
```

#### CAAnimationGroup（动画组）
```objc
CAAnimationGroup *group = [CAAnimationGroup animation];
group.animations = @[scaleAnimation, rotationAnimation, opacityAnimation];
group.duration = 1.0;
[layer addAnimation:group forKey:@"groupAnimation"];
```

#### CATransition（转场动画）
```objc
CATransition *transition = [CATransition animation];
transition.type = kCATransitionFade;
transition.duration = 0.3;
[view.layer addAnimation:transition forKey:@"transition"];
```

常用类型：
- `kCATransitionFade` - 淡入淡出
- `kCATransitionMoveIn` - 移入
- `kCATransitionPush` - 推出
- `kCATransitionReveal` - 揭示

## 面试题

### 基础题

#### 1. UIView Animation 和 Core Animation 有什么区别？

**答案：**
- **UIView Animation**：
  - 高级API，使用简单
  - 自动处理动画的开始和结束
  - 适合简单的属性动画
  - 基于Core Animation实现
  
- **Core Animation**：
  - 底层API，功能强大
  - 需要手动管理动画
  - 支持更复杂的动画效果
  - 性能更好，可以精确控制

#### 2. UIView Animation 的常用方法有哪些？

**答案：**
1. `animateWithDuration:animations:` - 基础动画
2. `animateWithDuration:animations:completion:` - 带动画完成回调
3. `animateWithDuration:delay:options:animations:completion:` - 完整参数
4. `animateWithDuration:delay:usingSpringWithDamping:initialSpringVelocity:options:animations:completion:` - Spring动画

#### 3. Spring动画的参数是什么意思？

**答案：**
- `damping`（阻尼系数）：
  - 范围：0-1
  - 值越小，弹性越大，震荡越多
  - 值越大，弹性越小，更平滑
  - 推荐值：0.7-0.8
  
- `initialSpringVelocity`（初始速度）：
  - 动画的初始速度
  - 0表示从静止开始
  - 正值表示有初始速度

#### 4. CABasicAnimation 的 fillMode 属性有什么作用？

**答案：**
- `kCAFillModeRemoved`（默认）：动画结束后恢复原状
- `kCAFillModeForwards`：动画结束后保持最终状态
- `kCAFillModeBackwards`：动画开始前显示初始状态
- `kCAFillModeBoth`：同时应用Forwards和Backwards

注意：使用`kCAFillModeForwards`时，通常需要设置`removedOnCompletion = NO`。

### 进阶题

#### 5. 如何实现动画的链式调用？

**答案：**
```objc
- (void)animateChain {
    [UIView animateWithDuration:0.3 animations:^{
        view.alpha = 0.5;
    } completion:^(BOOL finished) {
        [UIView animateWithDuration:0.3 animations:^{
            view.frame = CGRectMake(100, 100, 200, 200);
        } completion:^(BOOL finished) {
            [UIView animateWithDuration:0.3 animations:^{
                view.alpha = 1.0;
            }];
        }];
    }];
}
```

或者使用递归：
```objc
- (void)animateWithSteps:(NSArray *)steps index:(NSInteger)index {
    if (index >= steps.count) return;
    
    AnimationStep *step = steps[index];
    [UIView animateWithDuration:step.duration animations:^{
        // 执行动画
    } completion:^(BOOL finished) {
        [self animateWithSteps:steps index:index + 1];
    }];
}
```

#### 6. 如何实现动画的暂停和恢复？

**答案：**
```objc
// 暂停动画
- (void)pauseAnimation:(CALayer *)layer {
    CFTimeInterval pausedTime = [layer convertTime:CACurrentMediaTime() fromLayer:nil];
    layer.speed = 0.0;
    layer.timeOffset = pausedTime;
}

// 恢复动画
- (void)resumeAnimation:(CALayer *)layer {
    CFTimeInterval pausedTime = layer.timeOffset;
    layer.speed = 1.0;
    layer.timeOffset = 0.0;
    layer.beginTime = 0.0;
    CFTimeInterval timeSincePause = [layer convertTime:CACurrentMediaTime() fromLayer:nil] - pausedTime;
    layer.beginTime = timeSincePause;
}
```

#### 7. 如何优化动画性能？

**答案：**
1. **使用硬件加速**：
   - 使用`transform`和`opacity`属性（GPU加速）
   - 避免使用`frame`和`bounds`（CPU计算）
   
2. **减少视图层级**：
   - 减少参与动画的视图数量
   - 使用CALayer代替UIView（如果不需要交互）
   
3. **避免主线程阻塞**：
   - 不在动画过程中做耗时操作
   - 使用后台线程处理数据
   
4. **合理使用动画**：
   - 不要同时运行太多动画
   - 使用`shouldRasterize`优化复杂视图

#### 8. 如何实现自定义动画曲线？

**答案：**
使用`CAMediaTimingFunction`：
```objc
CAMediaTimingFunction *timingFunction = [CAMediaTimingFunction functionWithControlPoints:0.5 :0.0 :0.5 :1.0];
animation.timingFunction = timingFunction;
```

或者使用预定义的：
```objc
animation.timingFunction = [CAMediaTimingFunction functionWithName:kCAMediaTimingFunctionEaseInEaseOut];
```

### 原理题

#### 9. UIView Animation 的实现原理是什么？

**答案：**
1. UIView Animation基于Core Animation实现
2. 当调用`animateWithDuration:`时，系统会：
   - 创建一个CAAnimation对象
   - 将动画添加到Layer
   - 在动画过程中，系统会不断更新Layer的属性
   - 动画结束后，根据fillMode决定最终状态
3. 动画在Render Server进程中执行，不阻塞主线程
4. 使用硬件加速，性能更好

#### 10. Core Animation 的渲染流程是什么？

**答案：**
1. **提交阶段**：在主线程创建动画对象，提交到Render Server
2. **准备阶段**：Render Server准备渲染数据
3. **渲染阶段**：在GPU上渲染动画帧
4. **显示阶段**：将渲染结果显示到屏幕

关键点：
- 动画提交后，主线程可以继续处理其他任务
- 渲染在GPU上执行，性能好
- 使用垂直同步（VSync），保证60FPS

#### 实现步骤

1. **淡入淡出动画**
```objc
- (void)fadeInAnimation {
    [UIView animateWithDuration:0.3 animations:^{
        self.targetView.alpha = 1.0;
    }];
}

- (void)fadeOutAnimation {
    [UIView animateWithDuration:0.3 animations:^{

    }];
```

2. **缩放动画**
```objc
- (void)scaleAnimation {

    }];

```

3. **旋转动画**
```objc
- (void)rotationAnimation {
    [UIView animateWithDuration:0.3 animations:^{
        self.targetView.transform = CGAffineTransformMakeRotation(M_PI);
    }];
}
```

4. **组合动画**
```objc
- (void)combinedAnimation {
    [UIView animateWithDuration:0.5 animations:^{
        self.targetView.transform = CGAffineTransformConcat(
            CGAffineTransformMakeScale(1.5, 1.5),
            CGAffineTransformMakeRotation(M_PI / 2)
        );
        self.targetView.alpha = 0.5;
    }];
}
```

#### 关键代码

```objc
// 恢复transform
- (void)resetTransform {
    [UIView animateWithDuration:0.3 animations:^{
        self.targetView.transform = CGAffineTransformIdentity;
    }];
}
```

#### 性能优化点
- 使用transform而不是frame（GPU加速）
- 避免在动画过程中修改其他属性

```objc
- (void)keyframeAnimation {
    CAKeyframeAnimation *animation = [CAKeyframeAnimation animationWithKeyPath:@"position"];
    CGMutablePathRef path = CGPathCreateMutable();
    CGPathMoveToPoint(path, NULL, 100, 100);
    CGPathAddLineToPoint(path, NULL, 200, 100);
    CGPathAddLineToPoint(path, NULL, 200, 200);
    CGPathAddLineToPoint(path, NULL, 100, 200);
```

### 实操题4：实现进度条动画

#### 需求描述
使用Core Animation实现一个平滑的进度条动画。

#### 实现步骤

1. **创建进度条Layer**
```objc
- (void)setupProgressBar {
    self.progressLayer = [CALayer layer];
    self.progressLayer.backgroundColor = [UIColor blueColor].CGColor;
    self.progressLayer.frame = CGRectMake(0, 0, 0, 20);
    [self.progressBarView.layer addSublayer:self.progressLayer];
}
```

2. **实现进度动画**
```objc
- (void)setProgress:(CGFloat)progress animated:(BOOL)animated {
    CGFloat targetWidth = self.progressBarView.bounds.size.width * progress;
    
    if (animated) {
        CABasicAnimation *animation = [CABasicAnimation animationWithKeyPath:@"bounds.size.width"];
        animation.fromValue = @(self.progressLayer.bounds.size.width);
        animation.toValue = @(targetWidth);
        animation.duration = 0.3;
        animation.fillMode = kCAFillModeForwards;
        animation.removedOnCompletion = NO;
        [self.progressLayer addAnimation:animation forKey:@"progressAnimation"];
        
        // 更新实际值
        self.progressLayer.bounds = CGRectMake(0, 0, targetWidth, 20);
    } else {
        self.progressLayer.bounds = CGRectMake(0, 0, targetWidth, 20);
    }
}
```

#### 关键代码

```objc
// 使用CAShapeLayer实现圆形进度条
- (void)setupCircularProgress {
    CAShapeLayer *circleLayer = [CAShapeLayer layer];
    circleLayer.path = [UIBezierPath bezierPathWithArcCenter:CGPointMake(50, 50) 
                                                       radius:40 
                                                   startAngle:-M_PI / 2 
                                                     endAngle:M_PI * 3 / 2 
                                                    clockwise:YES].CGPath;
    circleLayer.strokeColor = [UIColor blueColor].CGColor;
    circleLayer.fillColor = [UIColor clearColor].CGColor;
    circleLayer.lineWidth = 5;
    circleLayer.strokeEnd = 0;
    [self.view.layer addSublayer:circleLayer];
    
    self.progressLayer = circleLayer;
}

- (void)setCircularProgress:(CGFloat)progress {
    CABasicAnimation *animation = [CABasicAnimation animationWithKeyPath:@"strokeEnd"];
    animation.fromValue = @(self.progressLayer.strokeEnd);
    animation.toValue = @(progress);
    animation.duration = 0.3;
    [self.progressLayer addAnimation:animation forKey:@"progressAnimation"];
    self.progressLayer.strokeEnd = progress;
}
```

#### 性能优化点
- 使用CAShapeLayer绘制，性能好
- 动画使用GPU加速
- 避免频繁创建Layer

## 常见问题

### Q1: 动画结束后如何保持最终状态？

**A:**
- UIView Animation：自动保持最终状态
- Core Animation：设置`fillMode = kCAFillModeForwards`和`removedOnCompletion = NO`，同时更新实际属性值

### Q2: 如何取消正在进行的动画？

**A:**
```objc
// UIView Animation
[view.layer removeAllAnimations];

// Core Animation
[layer removeAnimationForKey:@"animationKey"];
```

### Q3: 如何实现动画的链式调用？

**A:**
- 在completion回调中开始下一个动画
- 或者使用递归方法依次执行动画步骤

### Q4: 动画性能优化的关键点是什么？

**A:**
- 使用transform和opacity（GPU加速）
- 避免使用frame和bounds（CPU计算）
- 减少参与动画的视图数量
- 使用CALayer代替UIView（如果不需要交互）
