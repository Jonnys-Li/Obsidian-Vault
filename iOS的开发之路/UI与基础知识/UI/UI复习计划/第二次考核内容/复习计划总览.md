# UI复习计划总览（第15-27天）

## 计划说明

本复习计划涵盖iOS UI开发的核心知识点，包括视图生命周期、布局系统、渲染原理、UITableView、图片优化、UICollectionView、多Type Cell管理、动画系统和事件处理。每个主题都包含详细的面试题和实操题。

## 使用说明

1. **理论学习**：阅读每个主题的文档，理解核心概念
2. **面试准备**：练习文档中的面试题，掌握常见考点
3. **实践练习**：按照实操题步骤，完成代码实现
4. **代码示例**：运行项目中的示例代码，观察效果

## 项目结构


## 学习建议

1. **循序渐进**：按照天数顺序学习，每个主题都要充分理解
2. **理论结合实践**：看完文档后立即动手实现代码
3. **性能优化**：重点关注性能优化部分，这是面试重点
4. **总结归纳**：学完每个主题后，总结核心知识点和常见问题

## 面试重点

- 视图生命周期的调用顺序和用途
- Frame布局、AutoLayout和Masonry的区别和使用场景
- UIView和CALayer的关系，离屏渲染的检测和避免
- UITableView的Cell重用机制原理
- 列表性能优化的方法和策略
- 图片加载和缓存的实现原理
- 自定义Layout的实现方式
- 动画系统的使用和性能优化
- 响应者链和Hit-Test机制，手势冲突的解决方法
